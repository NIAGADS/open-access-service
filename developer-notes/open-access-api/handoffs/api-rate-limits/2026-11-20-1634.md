# Handoff: api-rate-limits

**Timestamp:** 2026-11-20 16:34 America/New_York
**Status:** completed

## Objective

Implement the approved minimal shared-factory rate limiter, excluding tokens.

## Work Completed

- Factory owns SlowAPI initialization, middleware, exception handling, and router exemptions.
- Anonymous clients share `API_RATE_LIMIT` across endpoints, keyed by remote IP.
- Only `ServiceRouter` is exempt. CORS and correlation middleware remain outside
  the limiter so rate-limit responses pass through them.
- Existing cachedb stores counters with the `open-access:ratelimit` prefix;
  legacy `keydb://` URLs are translated to `redis://` for the limiter.
- Updated root and service manifests and root lockfile (SlowAPI 0.1.10,
  limits 5.8.0, deprecated 3.0.1); project lockfile unchanged.
- Added compatible `ComponentBaseMixin` inheritance to the modified factory,
  as required by repository policy.
